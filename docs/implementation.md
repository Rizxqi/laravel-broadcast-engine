# ⚙️ Implementation

## Development Process

1. **Infrastructure setup** — Docker Compose for Icecast & Liquidsoap, network configuration
2. **Database design** — Incremental migrations: users → playlists → songs → pivot tables → refactor
3. **Core backend** — Eloquent models, RBAC Policies, controllers (PlaylistController, SongController)
4. **Audio pipeline** — `LiquidsoapConfigService` (generates `.m3u` & `radio.liq`), `AudioConverterService` (FFmpeg wrapper), `StreamController` (HTTP audio streaming with Range support)
5. **API layer** — Sanctum auth, REST endpoints for STB/external integration
6. **Admin panel** — User access management, playlist role assignment
7. **Monitoring** — Status polling against the Icecast API, with response caching

## Technical Challenges

- **Cross-platform file paths** — Paths differ between Windows (dev) and Linux (production); resolved using environment variables for all critical paths.
- **Docker volume mounting** — Files generated by Laravel (`radio.liq`, `.m3u`) need to be readable by the Liquidsoap container; resolved with shared volumes `./music` and `./liquidsoap`.
- **Liquidsoap config regeneration** — Every playlist change requires restarting the Liquidsoap container; no auto-restart solution yet (still manual via `docker restart liquidsoap`).
- **Icecast source detection** — Icecast's response format differs between a single source (object) and multiple sources (array); resolved by normalizing the response in code.
- **FFmpeg timeouts** — Large MP4 files could time out during conversion; resolved by setting `set_time_limit(300)` and a 300s timeout in `AudioConverterService`.
- **HTTP Range streaming** — Implemented Range header support for compatibility with audio players (VLC, STB) that require seeking.

## Additional Libraries & Tools

| Library | Reason for Use |
|---|---|
| **`james-heinrich/getid3`** | Reads audio metadata (duration, bitrate) from MP3/MP4 files during upload |
| **`guzzlehttp/guzzle`** | HTTP client for polling Icecast status (`/status-json.xsl`) |
| **`laravel/sanctum`** | Simple, built-in token-based API authentication for Laravel |
| **FFmpeg** (bundled) | Audio conversion MP4 → MP3, chosen for its reliability with cross-format conversion |
| **Liquidsoap** | Professional audio engine supporting M3U playlists, fallback, and pushing to Icecast |
| **Icecast2** | Battle-tested, open-source streaming server for audio broadcasting |

## Complex Logic

- **`LiquidsoapConfigService::generateLiquidsoapConfig()`** — Programmatically generates the `radio.liq` file from all playlists in the database. Each playlist becomes a separate Icecast mount point. Must be run every time a playlist changes.
- **`StreamController::streamWithRange()`** — Implements HTTP Range requests for audio streaming with seek support (resume, skip). Reads the file in 8KB chunks for memory efficiency.
- **`PlaylistController::checkStatus()`** — Polls the Icecast status API, normalizes the response format (object vs. array), and maps it to the playlist slug. Uses Laravel Cache to reduce load on Icecast.
- **RBAC in the Playlist model** — `getUserRole()`, `canEdit()`, `canView()` combined with a Laravel Policy for granular per-playlist, per-user access control.
